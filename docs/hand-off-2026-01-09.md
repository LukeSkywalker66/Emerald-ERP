```
SELECT c.connection_id, c.pppoe_username, c.direccion, cl.id AS cliente_id, cl.name, cl.doc_number
FROM connections c
LEFT JOIN clientes cl ON c.customer_id = cl.id
WHERE c.pppoe_username ILIKE '%usuarioprueba%';
```
