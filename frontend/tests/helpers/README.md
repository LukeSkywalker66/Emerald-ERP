# Helpers de Testing E2E (Playwright)

Este directorio contiene utilidades y helpers reutilizables para pruebas E2E.

- **login.ts**: Login automático con credenciales de testing.

## Buenas prácticas
- No importar helpers de este directorio en código de producción.
- Mantener helpers genéricos y desacoplados de los tests específicos.
- Documentar cada helper con ejemplos de uso.
